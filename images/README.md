# Images & Gameplay

[프로젝트 소개로 돌아가기](../README.md)

**현재 스크린샷, GIF 및 플레이 영상은 준비 중입니다.** 이 폴더에는 안내 문서만 포함되어 있습니다.

## 추가할 자료

| 자료 | 보여줄 내용 |
| --- | --- |
| 전투 스크린샷 또는 GIF | 스킬 실행과 전투 피드백 |
| 성장 화면 | Human / SourceBuild 성장 구조 |
| 원정 경로 선택 화면 | 후보 제시부터 선택 확정까지의 플레이 흐름 |
| 플레이 영상 | 전투, 성장, 원정 진행을 연결한 실제 플레이 |

실제 게임 실행 화면에서 자료를 선별하고, 개발 중인 화면에는 촬영 시점과 시연 범위를 표시합니다. 영상은 실제 접근 가능한 URL을 확보한 뒤 연결합니다.

외부·유료 에셋의 원본 파일은 배포하지 않습니다. 화면 자료도 포함된 리소스의 공개 조건을 확인한 뒤 추가하며, 개인 정보·개발용 비밀 값·비공개 관리 화면이 노출되지 않도록 검토합니다.
