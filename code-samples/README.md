# Code Samples

[프로젝트 소개로 돌아가기](../README.md)

**현재 공개 코드 샘플은 준비 중입니다.** 이 폴더에는 안내 문서만 포함되어 있습니다.

원본 `ShinInHa12/My-project`의 private code를 자동으로 복제하지 않습니다. 직접 작성한 코드 중 작성 권한, 의존성, 공개 범위를 확인한 파일만 선별하여 추가할 예정입니다.

## 선별할 주제

- Combat Ability Runtime의 상태 전이
- Human / SourceBuild 성장 상태와 전투 능력의 연결
- Hybrid Expedition의 후보 생성과 선택 확정
- Candidate snapshot 및 Save / Retry / Restore 생명주기
- 상태 일관성을 확인하는 Runtime Validation

위 목록은 샘플 선별 주제이며 현재 포함된 코드 목록이 아닙니다.

## 샘플에 함께 담을 내용

각 샘플에는 해결하려는 문제, 코드의 책임, 필요한 입력과 의존성, 실행 또는 검증 방법을 함께 설명합니다. 원본에서 일부만 발췌했다면 생략 범위와 단독 실행 가능 여부를 명시합니다.

직접 작성하지 않은 코드, 외부·유료 Unity Asset, 라이선스가 불명확한 파일, 인증 정보 및 비공개 프로젝트 데이터는 포함하지 않습니다. 원본 전체 공개나 전체 프로젝트 복제를 전제로 하지 않습니다.
